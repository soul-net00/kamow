# kamow# Kamow’s Birthday Page

A pink galaxy-themed birthday surprise for Kamow, with photos, animations, and birthday messages.

[Open the birthday page on Vercel](https://kamow.vercel.app/index%20%282%29.html)

## Open it on your computer

Download the HTML file and open it in your browser. The photos are embedded in the file. Keep your internet connection on to load the fonts and animation library.

## Publish the homepage

Upload the birthday HTML as `index.html` at the top level of this repo and commit it to `main`. Once the Vercel production deployment shows **Ready**, open [kamow.vercel.app](https://kamow.vercel.app/).
